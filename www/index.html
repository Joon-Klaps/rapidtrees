rapidtrees

Compute pairwise phylogenetic tree distances (Robinson–Foulds, Weighted RF, Kuhner–Felsenstein) from a BEAST .trees file — entirely in your browser via WebAssembly. Nothing is uploaded to a server. The matrix is streamed straight to a file on disk.

Burn-in & taxa
Output

Save uses the File System Access API where available (Chrome/Edge), with a download fallback for Firefox/Safari. Very large matrices may exceed browser memory limits on the fallback path.
