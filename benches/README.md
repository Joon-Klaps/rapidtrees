# Benchmarks

`memory_time_benchmark.rs` measures memory and time on simulated trees across taxon and tree counts. Run it with:

```bash
pixi run cargo bench --bench memory_time_benchmark
```

Trees are parsed **once** and their interned split IDs are reused across all pairwise comparisons. Parallelism is provided by [`rayon`](https://github.com/rayon-rs/rayon).
